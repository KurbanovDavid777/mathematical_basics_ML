# Mathematical Foundations for Machine Learning

## Project Description

This repository contains laboratory assignments focused on **mathematical methods, numerical optimization, and data analysis** for machine learning.

The main goal of the project is to reinforce theoretical knowledge through the **practical implementation of mathematical algorithms and data analysis techniques**.

---

## Labs

### Lab 1 — Matrix Decomposition

Implementation and analysis of matrix decomposition methods, including:

* Principal Component Analysis (PCA)
* Kernel PCA

### Lab 2 — Numerical Optimization

Implementation and analysis of numerical optimization methods, including:

* BFGS
* L-BFGS
* Numerical gradient computation

### Lab 3 — Univariate Data Analysis

Univariate statistical analysis for identifying anomalies, relationships, and potential issues in datasets in order to improve data quality.

### Lab 4 — Multivariate Data Analysis

Multivariate analysis for identifying relationships and dependencies between variables and improving overall data quality.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/KurbanovDavid777/mathematical_basics_ML.git
```

### 2. Navigate to the project directory

```bash
cd mathematical_basics_ML
```

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 4. Run a laboratory assignment

Open the `notebooks/` directory and select the required Jupyter Notebook.

The corresponding task descriptions are available in the `task/` directory.
